# Campañas de adquisición de Solennix

El sistema de marketing activo es **Adquisición 2026 — “Tu talento crea. Solennix organiza.”** Su única prioridad comercial es adquirir nuevos organizadores y ayudarlos a llegar al primer valor. La conversión a suscripciones queda fuera del alcance.

## Ruta rápida

1. Lee [acquisition-2026/README.md](acquisition-2026/README.md).
2. Completa la medición P0 antes de activar medios pagados.
3. Produce las primeras 2 semanas del calendario e inicia la distribución orgánica.
4. Agrega inversión pagada solo después de verificar la atribución desde la fuente hasta la activación.
