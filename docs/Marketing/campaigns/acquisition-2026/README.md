# Adquisición 2026 — Tu talento crea. Solennix organiza.

Este es el sistema de adquisición de Solennix listo para lanzamiento. Reemplaza las campañas anteriores y coordina posicionamiento, contenido, producción creativa, distribución en comunidades, pruebas pagadas, atribución, activación y decisiones semanales.

## Decisión

| Elemento | Decisión de campaña |
| --- | --- |
| Objetivo | Adquirir nuevos organizadores de eventos y llevarlos al primer valor |
| Conversión principal | **Organizador activado:** usuario registrado que crea su primer evento en 7 días |
| Mercado principal | México para validación pagada; LATAM hispanohablante para distribución orgánica |
| Destino principal | `https://solennix.com/register` |
| Destinos secundarios | App Store y Google Play para piezas orientadas a móvil |
| Oferta | Empezar gratis, sin tarjeta. Sin descuentos ni urgencia falsa |
| Plataforma de campaña | **Tu talento crea. Solennix organiza.** |
| Firma | Cada detalle importa |
| Objetivo excluido | Suscripciones, ingresos por planes o promoción de precios |

## Puertas de lanzamiento

| Puerta | Estado | Regla |
| --- | --- | --- |
| Producto y tiendas disponibles | Verificado | Web, iOS y Android están disponibles; evitar números de versión fijos |
| Afirmaciones | Listas | Usar solo las afirmaciones aprobadas en [02-messaging.md](02-messaging.md) |
| Creatividad orgánica | Lista | Empezar con las primeras 2 semanas de [05-calendar.csv](05-calendar.csv) |
| Atribución de fuente | Parcial | El embudo actual llega al primer inicio de sesión, pero no a la activación por primer evento |
| Medios pagados | **Bloqueados hasta completar P0** | No invertir hasta verificar el P0 de [09-measurement.md](09-measurement.md) |
| Testimonios | No listos | No usar nombres, citas, estrellas ni resultados sin evidencia firmada |

## Primeras 72 horas

1. Confirmar accesos a Meta, TikTok, YouTube, LinkedIn, Pinterest, X/Threads, WhatsApp Business, App Store Connect, Play Console y administración de Solennix.
2. Verificar la medición P0 y los enlaces de campaña.
3. Publicar el manifiesto, el carrusel de diagnóstico del caos y el primer demo de producto de 15 segundos.
4. Participar en 10 conversaciones relevantes de comunidades sin insertar enlaces no solicitados.
5. Registrar la línea base a diario; no declarar un canal ganador antes de contar con datos de activación.

## Definición de éxito

La campaña funciona cuando produce una fuente repetible de **organizadores activados**, no cuando acumula vistas o seguidores. Un canal puede tener mucho alcance y aun así detenerse si las personas no se registran, verifican su correo, inician sesión y crean su primer evento.
