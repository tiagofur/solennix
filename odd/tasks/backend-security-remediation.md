# Backend security & reliability remediation

Fixes from the 2026 backend audit (4 parallel explore agents + parent spot-checks of every critical/high). All findings CONFIRMED unless noted. Audit memory: Engram topic `backend-security-audit` (obs 2273).

## Specs

### Critical

- S1 (Apple takeover): `auth_handler.go:1799` `if email == "" && req.Email != nil { email = normalizeEmail(*req.Email) }` — client body email trusted for account matching/linking (`LinkAppleAccount:1873`); same forgeable fallback in `AppleCallback:2098` via form field `user`. `validateAppleIDToken:2334` parses `email_verified` but never enforces it. Fix: email trusted only from signed id_token with `email_verified=true`; never from request body/form. Google flow (`:1726`) is the reference pattern.
- S2 (NaN money): `payment_submission_handler.go:327` `fmt.Sscanf(amount, "%f", &amountFloat)` accepts `NaN`/`Inf`; `amountFloat <= 0` and `amountFloat > max` are both false for NaN (verified empirically) → NaN payments corrupt SUMs/dashboards/auto-confirm. Fix: reject non-finite in parse + `ValidatePayment` (`validation.go:198`).
- S3 (financial cascade delete): `user_cleanup_repo.go:213` `DELETE FROM users WHERE id = $1` with `ON DELETE CASCADE` on payments/payment_submissions/events/subscriptions/audit_logs; `user_cleanup_service.go:49` advances inactivity stage even when warning email fails. Fix: anonymize + tombstone, not hard delete; gate stage advance on email delivery.

### High

- S4 (SSRF + traversal): `pdf_handler.go:59-83` fetches user-controlled `logo_url` (set via `PUT /users/me` `auth_handler.go:1263` with zero validation) — no scheme/host allowlist, unbounded `io.ReadAll`; `pdf_handler.go:582-590` local read `/api/uploads/../..` escapes uploadDir. Fix: allowlist + block private IPs + `io.LimitReader`; reject `..` in relPath.
- S5 (webhook idempotency): `subscription_handler.go:256` `TryInsert` marker committed BEFORE processing; apply errors `slog.Error`-only then `200 OK` (lines 302, 366) → Stripe retry discarded as duplicate; paying user stuck on wrong plan. Same in RevenueCat (~:430). Fix: mark-processed after successful apply or delete marker + 5xx on failure.
- S6 (stock integrity): `crud_handler.go:896` `DeductSupplyStock` error only `slog.Warn`, outside event tx; re-confirm double-deducts; `GREATEST(0, stock - qty)` masks negative stock; `UpdateClientStats` same (lines 885-891). Fix: deduction ledger keyed by event (idempotent) inside tx; surface errors.
- S7 (goroutine pileup): `middleware/auth.go:386` + `audit.go:69` fire-and-forget `go func` with `context.Background()` per authenticated/mutating request → unbounded goroutines+conn waits under load. `security_audit.go:14-28` bounded-queue pattern is the reference. Fix: throttle before spawn + `context.WithTimeout` or bounded queue.
- S8 (ConvertToEvent race): `public_request_repo.go:496` `SetEventIDTx` lacks `WHERE event_id IS NULL` guard/lock → double-click creates duplicate client+event. Fix: guard + row lock.
- S9 (decompression bombs): `storage/s3.go:397` + `local.go:105` `image.Decode` without dimension check; presigned path accepts `image/svg+xml` (`s3.go:141`) and PUT enforces no size; `s3.go:207` unbounded `io.ReadAll(obj.Body)`. Fix: `DecodeConfig` max-pixels gate; reject SVG; size caps.
- S10 (job panics kill server): `cmd/server/main.go:222-396` 9+ background jobs as bare `go func` without `recover()`. Fix: shared safeGo wrapper with recover+sentry.

### Medium

- S11: `pdf/builder.go:428` `Output()` unnamed returns + recover → `(nil,nil)` false success, empty PDF served as 200 (parent-verified). Fix: named returns, set err in defer.
- S12: password change/reset does not revoke outstanding access JWTs (`auth_handler.go:1170,1247`) — up to 24h window.
- S13: rate-limit key spoofable via leftmost XFF when `TrustProxy=true` (`ratelimit.go:116`). Fix: last untrusted hop.
- S14: cookie `Secure` derived from `X-Forwarded-Proto` header (`auth_handler.go:302` etc., `csrf.go:80`). Fix: env/config-driven.
- S15: stored-XSS enabler: review `Comment`/`OrganizerResponse` stored+served raw, no sanitize/length cap (`event_review_handler.go:169,255`, `public_review_mapper.go:78`).
- S16: raw `json.NewDecoder` bypasses 1MB cap on public review submit + beacons (`event_review_handler.go:117`, `registration_funnel_handler.go:44`, `site_page_view_handler.go:33`).
- S17: payment remaining-balance cap TOCTOU, not re-checked in review tx (`payment_submission_handler.go`).
- S18: `UpdateEvent`/inventory read-modify-write without FOR UPDATE/version (`crud_handler.go`, `inventory_repo.go`).
- S19: money `float64` domain-wide (`models.go:121,259,510`). Fix: int-cents/pgtype.Numeric.
- S20: `MXN` hardcoded in receipts/pushes ignoring `events.currency` (`crud_handler.go`, `notification_service.go`).
- S21: `009_move_logo.up.sql` drops `clients.logo_url` without backfill; `080` drops `public_leads` (flagged intentional, verify).
- S22: geocoding cache never evicts (`geocoding_service.go:149`).
- S23: turnstile not enforced on shared-link submit (`request_link_handler.go:368`) while profile path enforces it.

S33: partial files left on failed local writes (`local.go:60`). S34: `rows.Err()` ignored in `live_activity_token_repo.go:55`. S35: staff assignment notification permanently suppressed after one failure (`event_repo.go:771`). S36: `processed_webhook_events`/`notification_log` no retention. S37: unbounded page/OFFSET on public directory (`pagination.go:29`). S38: `inboundClientIP` trusts XFF ungated (`inbound_analytics.go:67`).
